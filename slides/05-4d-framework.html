The 4D Framework

四項互相連結的核心能力。無論工具怎麼換，這套判斷方式都能帶走。

D
Delegation
委派

先決定要不要用、用在哪、人要留下什麼。

培訓現場課綱與學習目標你定；講義初稿可以交給 AI。

D
Description
描述

說清楚產出、作法、協作態度。提示詞只是描述的其中一種形式。

培訓現場產出＝45 分鐘課綱；過程＝先問這班學員程度。

D
Discernment
辨別

用你的專業看輸出、過程與互動。培訓師最不該外包的，就是判斷。

培訓現場活動好不好玩，不如先問適不適合這一班。

D
Diligence
審慎

教材若使用到AI則必須揭露、學員資料要守住、上課堂的內容由你背書。

培訓現場學員作業不要丟進公用模型；教材要標 AI 協助。

Effective 有效 · Efficient 高效 · Ethical 合乎倫理 · Safe 安全
