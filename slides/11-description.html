Description 描述

不只是寫提示。是建立一個協作環境。AI 讀不到你的心思，也不是自動販賣機。

Product
產出
你要什麼

輸出、格式、受眾、風格、長度。先定義「完成」長什麼樣子。

問句給我一份 45 分鐘課綱，給現場培訓師，每段標時間盒。

Process
過程
怎麼做

方法、步驟、框架。怎麼處理，可能跟最終目標一樣重要。

問句先問我這一班的先備知識，再出三種活動讓我挑。

Performance
表現
怎麼互動

簡潔還是詳細、挑戰還是支持。指定協作態度，而不只指定答案。

問句當我的備課夥伴：先反問，不要一次寫完整堂課。
